# Download versions

For a new installation use [suite 0.1.6](mcbhsu-suite-0.1.6-candidate.zip).
The separate [0.1.6 published-filter companion](mcbhsu-paper-example-suite-0.1.6.zip)
requires that installation. These archives include complete references.

Suite 0.1.6 revises documents and package metadata; its six statistical files
are unchanged from 0.1.5. macOS execution has been checked; native Windows
package evidence is for 0.1.5. See [validation](../docs/validation.md).

The older [suite 0.1.5](mcbhsu-suite-0.1.5-candidate.zip) and
[original companion](mcbhsu-paper-example-suite-0.1.4.zip) are preserved unchanged
for historical validation. Their embedded guidance predates the current reference
revision. SHA-256 digests for all four archives are in [SHA256SUMS](SHA256SUMS).
